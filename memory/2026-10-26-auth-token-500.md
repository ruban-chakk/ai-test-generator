# Authentication token 500 — 2026-10-26

- Symptom: `POST /api/v1/auth/token` returned HTTP 500 from the local web app.
- Root cause: the Docker PostgreSQL container had exited with code 255. The token handler failed in `enforce_auth_rate_limit` while opening its database connection, before username/password validation.
- Fix: restarted the existing `ai-testgen-postgres` container using its persistent volume, waited for the database health check, and recreated the worker containers so they reconnected to the database.
- Evidence: `/health/ready` returns `200` with `{"status":"ready","database":"healthy"}`; an invalid login now returns the expected `401 Unauthorized` rather than `500`.
- Data impact: no volume or database reset was performed.
